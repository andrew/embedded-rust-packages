# Shared code

## http.rb

Faraday connection factory with retry, redirect-follow, and a project User-Agent. `conn(base_url)` returns a connection; every script that hits an API requires it.

## c_vendoring.rb

`CVendoring.vendors_c?(crate_name)` classifies a crate as one that compiles vendored C/C++/asm rather than only declaring FFI to a system library. The rule is: `*-sys` / `*-src` / `tree-sitter-*` names, plus an explicit list (`ring`, `blake3`, `cxx`, `psm`, ...), minus `*-rs-sys` pure-Rust reimplementations, the retep998 winapi `*-sys` family, and GTK/GL/wasm/Apple/OS-service FFI-only names.

`CVendoring.upstream_for(crate, version)` returns `[upstream_name, upstream_version]` when the crate encodes it in `+metadata` (`zstd-sys@2.0.10+zstd.1.5.6`) or has an entry in `UPSTREAM_TABLE`. The table is regenerated by `upstream_version.rb --all`.

`CVendoring::UPSTREAM_ECOSYSTEMS` lists the OSV distro-ecosystem strings `advisories.rb` queries for upstream CVE discovery.

## repology.rb

`Repology.osv_packages(upstream)` maps an upstream project name to the `(osv_ecosystem, srcname)` pairs OSV distro queries take, via the Repology API. Port of Homebrew/advisory-database's `RepologyIndex` keyed on upstream project rather than Homebrew formula. Responses cache to `cache/repology/<project>.json` for a week.

Repology tracks crates.io as a repository but groups `-sys` crates as their own projects (`rust:libz-sys`) rather than under the upstream (`zlib`), so the crate -> upstream step still comes from `c_vendoring.rb`.

## bin/scc

A shell shim that finds the real `scc` on `PATH` and execs it with `--no-gitmodule` prepended. brief hardcodes its scc arguments with no passthrough, and scc skips submodule directories by default; the shim makes brief's `lines.by_language` counts include fetched submodule content so they agree with brief's own `languages[]` walk. `scan.rb` prepends `bin/` to `PATH` when invoking brief.

Used by: `vendors_c?` in [`native.rb`](native.md) and [`advisories.rb`](advisories.md); `upstream_for` in [`advisories.rb`](advisories.md); `UPSTREAM` regexes in [`upstream_version.rb`](upstream_version.md). Repology in [`crate_cve_ranges.rb`](crate_cve_ranges.md).

## data/rejected.txt

`<crate> <CVE>` pairs that [`crate_cve_ranges.rb`](crate_cve_ranges.md) drops after the NVD range check. Use it for CVEs whose CPE product matches but whose vulnerable component is code the crate's build.rs excludes (MiniZip in zlib, `xzgrep` in xz, `bzip2recover` in bzip2).
